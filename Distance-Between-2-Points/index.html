Slide 5: General 2D Distance Formula
Distance Between Points (x1, y1) and (x2, y2)
d = √ (x1 - x2)2 + (y1 - y2)2

Derived directly from Pythagoras' Theorem!
Horizontal distance leg = (x1 - x2)  •  Vertical distance leg = (y1 - y2)

Slide 6: 2D and 3D Distance Formulas

The distance between two points in 2D

In a two-dimensional (2D) space, the distance between two points, A(x1, y1) and B(x2, y2) is:

d = √ (x2 - x1)2 + (y2 - y1)2

The distance between two points in 3D

In a three-dimensional (3D) space, the distance between two points, A(x1, y1, z1) and B(x2, y2, z2) is:

d = √ (x2 - x1)2 + (y2 - y1)2 + (z2 - z1)2

Reveal Solution (b)

Reveal Solution (c)

Reveal Solution (d)
